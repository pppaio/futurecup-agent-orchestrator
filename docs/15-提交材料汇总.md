## 二、可使用的安装程序

- **一键启动脚本**：仓库根目录 **`start.bat`**（Windows）。双击后自动完成：依赖安装 → 无头浏览器下载（仅首次）→ 启动服务 → 打开浏览器。Node.js 20+ 即可，无需数据库 / GPU / API Key。
- 命令行安装：`cd agent-platform && npm install && npx playwright install chromium && npm run serve`。

## 三、Demo 与说明文档

- **网页 Demo（零成本）**：不配置 API Key 时自动进入演示模式，打开 http://localhost:3000 即可完整演示：分析 → 生成 → 硬验证 → 修复循环 → 评分返工 → 人工确认 → 版本追溯；任务台可切换「自主编排」「智能·省流调度」，可接任意 OpenAI 兼容供应商。
- **命令行 Demo（20 个）**：`npm run demo:workflow`（修复闭环）、`demo:rollback`（退步回滚+返回第一版）、`demo:quality`（评分返工收敛）、`demo:auto`（自主编排）、`demo:scheduler`（调度打分）、`demo:interrupt`（秒级中断续跑）等。
- **演示路径说明**：见 `安装与使用说明.md` 第三节（3 分钟走一遍核心卖点）。
- **演示视频**：（录制后填链接）分镜与旁白见仓库 `docs/视频脚本-终版.md`、`docs/06-视频分镜.md`、`docs/07-旁白文案.md`。
