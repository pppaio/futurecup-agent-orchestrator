# PPT 合规清单（依据《2026未来杯PPT模版.pptx》）

> 模板共 6 页骨架：封面 / 目录 / 内容页 ×2 / 大会PPT提示 / 谢谢观看。
> **现状：我们的 `presentation/slides.html` 是自己搭的 HTML，不含思源黑体、封面也没有四要素 → 不合模板。**

## 1. 硬性格式（模板内文字直接抄下来的）

| 位置 | 要求 |
|---|---|
| 封面 标题 | 思源黑体 **Bold，32 号**，**不加书名号** |
| 封面 信息 | 团队名称 / 演讲人 / 指导教师 / 学校 —— 思源黑体 **Bold，20 号** |
| 目录页 | 一级标题 思源黑体 Bold **20 号**；二级「x.y」 思源黑体 Normal **18 号** |
| 内容页 小标题 | 思源黑体 **Bold，24 号** |
| 末页 | 「谢谢观看 / Thanks」 |
| 正文字号 | 模板未规定（建议 ≥14 号，投影可读） |

## 2. 合规红线（模板第 5 页原文）

1. 请勿出现**国家领导人**照片、头像；
2. 请勿出现**国家地图**；
3. 请勿使用**国旗国徽、党旗党徽、天安门**等国家象征；
4. 现场着正装或商务休闲装。

## 3. 页数

赛题一要求正文 **10~15 页**。模板骨架 6 页只是格式示例，实际按 10~15 页组织。

## 4. 最省力的补救顺序（约 1~1.5 小时）

1. **先装字体**：思源黑体（Source Han Sans SC）。没装的话 PowerPoint 会 fallback，导出 PDF 字体不对 → 白做。
2. 打开 `2026未来杯PPT模版.pptx` → 另存为我们的文件（保留母版）。
3. 按模板页结构重建 10~15 页，把 `presentation/slides.html` 里的内容（架构图/流程图/实验表）拷过来。
4. 封面填四要素：团队名称 / 演讲人 / 指导教师 / 学校（问学校或指导教师确认全称）。
5. 层级字号按上表调（32/24/20/18）。
6. 导出 PDF 覆盖 `docs/讲解PPT.pdf`；**pptx 原件也留着**（决赛现场答辩要用）。
7. 截图检查：**别露出 API key、余额、真实姓名/手机号**。

## 5. 需要向赛方/通知核对的两件事

- [ ] 提交文件的**命名规范**（如「赛题一-队伍名-项目名.pptx」）
