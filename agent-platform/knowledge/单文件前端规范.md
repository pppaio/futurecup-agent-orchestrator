# 单文件前端规范（知识库）

## 硬约束（H1~H4）
- H1 单文件：CSS/JS 全部内联，禁止任何外部资源：`<script src>`、`<link href>`、`@import`、fetch、网络图片一律不允许。
- H2 必须可交互：canvas 或 DOM 实现可操作玩法/功能，有键盘/鼠标事件处理。
- H3 图形类需求必须用 `<canvas>` 绘制并至少填充一帧背景，便于机器检测"渲染非空"。
- H4 零报错运行：不引用未定义变量、不依赖未加载的库、语法正确。

## 机器验收口径
- 硬验证判定：页面加载成功 && 控制台/页面错误为 0 && (图形类: canvas 非空 | 工具类: DOM 节点 ≥ 12) && 交互脚本不抛错。
- 首帧绘制：headless 浏览器冷启动偶发不绘帧，务必在脚本末尾立即调用 requestAnimationFrame 绘制第一帧。

## 常见坑
- canvas 尺寸用属性而非 CSS 拉伸（width/height 属性设置像素尺寸）。
- 键盘事件绑定在 window 上，避免焦点在 canvas 上收不到按键。
- 避免 `document.write`、同步 XHR；避免访问跨域资源。
- 碰撞检测注意帧率差异：用速度 × 帧间隔做位移，避免高刷新率下穿透。
