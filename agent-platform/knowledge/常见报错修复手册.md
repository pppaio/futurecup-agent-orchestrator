# 常见报错修复手册（知识库）

## 未定义变量 / ReferenceError
- 症状：`xxx is not defined`。修复：补齐声明；检查函数作用域与拼写；避免在定义前使用（TDZ）。

## 空属性访问 / TypeError
- 症状：`Cannot read properties of undefined (reading 'y')`。修复：访问前判空或给默认值；数组循环用索引边界检查；删除元素后先判 `alive` 再使用。

## JSON 转义错误
- 症状：模型输出 JSON 时 html 字段内引号未转义导致解析失败。修复：html 内字符串全部转义（\" 换行 \\n）；禁止把代码块围栏带进 JSON。

## 白屏 / 画布为空
- 症状：canvas 无像素。修复：确认在 load 后执行绘制；立即调用一次 requestAnimationFrame；canvas 用属性设置宽高。

## 事件无响应
- 症状：按键/点击无效。修复：监听器绑定在 window/document；用 keydown 而非 keypress 监听方向键；阻止默认滚动行为。
