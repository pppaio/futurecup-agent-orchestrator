# 小游戏设计要点（知识库）

## 玩法循环
- 核心循环要一眼可玩：输入 → 更新状态 → 判定 → 渲染，每帧一次。
- 目标与反馈：分数/生命值/关卡进度要有即时视觉反馈。

## 碰撞检测模式
- 圆与矩形：先找最近点再算距离，注意边界（球在砖角/拍侧）。
- 砖块阵列：用对象数组管理（x/y/w/h/alive），命中即置 alive=false，避免拼接坐标字符串。

## 计分与关卡状态机
- 状态机至少含：进行中 / 胜利 / 失败 / 暂停；状态切换要清空或重置相关变量。
- 计分规则明确：普通砖 10 分、道具砖 20 分之类，写进 acceptance。

## canvas 绘制模式
- 每帧先 fillRect 清屏再绘制实体；文字用 fillText 前设置 font/颜色。
- 颜色表用数组索引而非 if 链。
